## 🛠️ Prasyarat (Prerequisites)

Sebelum menjalankan proyek ini, pastikan komputer Anda telah terpasang:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (versi stable terbaru)
- [Dart SDK](https://dart.dev/get-dart)
- Editor: [VS Code](https://code.visualstudio.com/) / [Android Studio](https://developer.android.com/studio)
- Flutter & Dart Extension untuk VS Code / Android Studio

---

## 🚀 Cara Menjalankan Proyek (Getting Started)

1. **Clone repositori ini:**
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd pemrograman-mobile-c
   ```

2. **Unduh dependencies / packages:**
   ```bash
   flutter pub get
   ```

3. **Jalankan aplikasi:**
   ```bash
   flutter run
   ```
